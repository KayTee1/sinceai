# Since AI Hackathon 2026: event facts

Researched 2026-11-05 from public pages. **Verify against sinceai.app and
the official rules on the day**; organizer updates win over this file.
Sources: https://sinceai.ai/hackathon, https://www.utu.fi/en/news/events/since-ai-hackathon-2026-1000-ai-builders-coming-to-turku

## In a nutshell

- Free, in-person, ~72-hour AI hackathon in Turku, Finland, run by Since AI
  (a nonprofit founded by University of Turku students). MLH member event.
- 1,000+ builders, teams of up to 5. We are 2 developers.
- ~15 **company challenges** (e.g. Valmet, Bayer, Elisa, Traficom, FORCIT).
  Teams pick one; **the choice is final**.
- Goal: build a **working AI product** for a real company problem.
  Working demos are prioritized; slides are "optional, never a substitute".

## Submission (in sinceai.app)

Required: project name, one-sentence tagline, description, technologies used,
repository link, **YouTube demo video**, source code .zip, acceptance of the
challenge's IP terms. Optional: demo URL, pitch deck, supporting docs.

## Judging and prizes

- Each company judges its own challenge: €2,000 / €750 / €250
  (FORCIT: €3,000 / €1,500 / €500).
- Participant vote (each builder makes 20 comparisons).
- Five finalists pitch live to a jury; overall winner gets €5,000.
- Extra awards: MLH categories, Red Hat OpenShift AI award, FIWARE award.
- Published scoring criteria: none found. Ask the company what they value.

## Rules that affect how we build

- AI-assisted development is allowed and encouraged. We must understand,
  verify and be able to explain what we ship, and **disclose main AI tools**.
- Keep pre-existing work separate from what is built at the event.
- Licences and each challenge's data restrictions apply. FORCIT requires a
  paper NDA before data access.
